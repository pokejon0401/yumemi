# Claude Code instructions

Follow `AGENTS.md` and `docs/EDITORIAL.md` for every task. This is a Japanese Astro editorial site, not a generic landing page.

For article requests, create or edit Markdown in `src/content/articles/`; do not hard-code articles in Astro pages. Keep new articles as drafts unless the user explicitly asks to publish and the sources/checklist are complete. Run `npm run build` after changes and report any validation failure.
