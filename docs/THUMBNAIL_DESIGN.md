# YUMEMI 記事サムネイルのデザインルール

制定：2026-10-31

## コンセプト

「気になる夢を調べて、安心して今日を過ごせる」を、温かい紙の上のエディトリアルイラストで表す。大人の女性向け生活誌のような落ち着きと、夢らしい詩的なモチーフを共存させる。

## 統一するもの

- 横長3:2。掲載画像は1200×800、一覧用は600×400のJPEG。
- 温かいアイボリーの紙地。ダスティローズ、セージ、ラベンダーを基調に、必要な部分だけ濃いインク色で締める。
- ガッシュ・色鉛筆の柔らかな質感と自然な陰影。写真や一般的な単色アイコンとの混在を避ける。
- 一つの主役と少数の脇役、余白を持つ構図。主役は中央80%以内に収める。
- 画像にタイトル・数値・ロゴを焼き込まない。記事タイトルはHTMLで表示する。
- 恐怖、性的な場面、負傷、死、災害の被害を直接再現しない。記事の内容を安全な比喩や静物で表現する。

## 記事ごとに変えるもの

同一画像を全記事に使わず、各記事の主要な疑問に対応するモチーフを選ぶ。月や花を入れるだけの差分にしない。

| 内容 | モチーフの考え方 |
|---|---|
| 追いかけられる夢 | 曲がる小道、長い影、光の差す出口 |
| 夢日記 | 白紙のノート、鉛筆、しおり |
| 眠りの改善 | 寝具、窓、静かな就寝準備 |
| 繰り返す悪夢 | 繰り返す月や、輪を描くリボン |
| 相談先 | 向かい合う椅子と会話を待つ机 |
| 火事・地震・津波 | 陶器や紙による象徴的な炎・家・波 |
| 歯が抜ける夢 | 陶器の歯、鏡、布。損傷や口腔写真を使わない |
| 人が死ぬ夢・故人の夢 | 空の椅子、アルバム、花。喪失と記憶の違いを構図で表す |
| 恋愛の夢 | 間隔や向きが異なるカップ、折り紙の鳥、リボン |

## 保存と掲載

- 保存先は `public/images/thumbnails/`。記事の英語スラッグをファイル名にする。
- frontmatterの `hero` に1200px版、`thumbnail` に600px版を指定する。
- 記事カードでは同じリンク内の記事タイトルが画像の内容を補うため、画像の代替テキストは空にし、タイトルの重複読み上げを避ける。
- `hero` は記事のOGPにも利用する。画像が記事の内容と矛盾しないことを確認する。
- 一覧は画面幅に合うサイズを選択し、遅延読み込み・画像の幅と高さ指定で読み込み負荷とレイアウトのずれを抑える。
- 本文の図解・イラストはこのサムネイルとは別に管理する。

## 新規制作の確認

1. 記事の主要な疑問を読み、固有のモチーフを決める。
2. 既存シリーズと色・紙地・タッチを揃え、組み込みのimagegenで生成する。
3. 脅威的な描写、文字、崩れた形、題材の取り違えを目視で確認する。
4. 同じ画角で2サイズを作り、frontmatterに割り当てる。
5. 一覧・カテゴリ・関連記事・OGPへの反映と、画像の配信を確認する。

初期25記事の生成プロンプトと画像の対応は `thumbnail-prompts.json` に保存する。
