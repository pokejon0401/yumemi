# YUMEMI編集・SEOガイド

## 読者と目的

悪夢や睡眠の質に悩む大人の女性が、夢を入口に睡眠と体調を振り返り、必要なら適切な支援へ進める情報を作る。将来の睡眠・夢・体調・天気・服装アプリにつながるが、記事の主目的を販売にしない。

## 記事の原則

1. 検索意図に最初の200字で回答する。
2. 医学的説明、一般的なセルフケア、夢占いの解釈を混同しない。
3. 医学的な断定・診断・治療指示をしない。
4. 厚生労働省、学会、公的研究機関、診療ガイドライン、査読論文を優先する。
5. 実在しない著者、監修者、体験談、調査、出典を生成しない。
6. 症状が続く、生活に支障がある、危険な行動を伴う場合の相談目安を記載する。
7. 文字数の水増しや、検索語だけを変えた重複記事を作らない。

## 内部リンク

- 各記事から同カテゴリの柱記事へ1本以上リンクする。
- 読者の次の行動に合う関連記事へ2本以上リンクする。
- アンカーテキストはリンク先の内容が分かる自然な日本語にする。
- 孤立記事を作らない。新規記事公開時は既存記事からもリンクを返す。

## 公開チェック

- [ ] タイトルと30〜160文字のdescriptionが内容を正確に表している
- [ ] 事実と占い解釈が分かれている
- [ ] 健康上の主要な主張に信頼できる出典がある
- [ ] 著者・監修者表記が事実である
- [ ] 公開日と更新日が正しい
- [ ] 内部リンクと参考資料のURLが有効である
- [ ] 相談目安と免責が適切である
- [ ] `npm run build` が成功する
